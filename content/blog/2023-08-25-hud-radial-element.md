Radial HUD Element Sketch, (left) and vectorized version (right)

While scouring the Internet for design inspiration for my website, I came across a lot of geometric HUD (Heads-up Display) elements and thought, "I want one too!". It's been several years since I last did vector art, so one week-end, I tried my hand in designing one.

On Procreate, I sketched out the look-and-feel. Then in Affinity Designer, I laid out a radial grid and fleshed out the elements one by one.

While the element is mainly aesthetic and is not a viable HUD indicator, I'm pretty happy with the end result.

I'm sure the SVG elements can still be optimized, and if one day I'm brave enough, I can try coding them by hand.
